🤖 Asisten AI MOMO

Ngobrol & perintah robot pakai AI (Gemini + cadangan Groq, gratis, tanpa kartu kredit). Isi KEDUA API Key dulu, baru bisa mulai ngobrol:

  1. Buka aistudio.google.com/apikey, login pakai akun Google, tekan "Create API key", copy key-nya (diawali "AIza...").
  2. Buka console.groq.com/keys, login/daftar, buat API key, copy key-nya (diawali "gsk_...").
  3. Tempel kedua key itu di kolom di bawah ini, lalu tekan Simpan.

Kedua key cuma tersimpan di HP kamu sendiri (browser), langsung dipakai ngobrol ke server Google/Groq, tidak lewat server lain. MOMO otomatis pindah ke Groq setiap kali Gemini gagal/kuota penuh.
